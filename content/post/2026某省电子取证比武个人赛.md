SetWindowsHookExW(13,(HOOKPROC)fn,ModuleHandleW,0)：这是最关键的函数调用。参数 13 在Windows API中代表宏WH\_KEYBOARD\_LL（低级键盘钩子）。最后的参数0表示这是一个全局钩子（拦截系统内所有线程的按键，不局限于当前窗口）。此函数将恶意或监控代码的回调函数fn注入系统。此后，用户按下的每一个键，系统都会先交给fn处理（它可以记录按键、拦截按键或篡改按键）

WH\_KEYBOARD\_LL及其对应的数值13具体定义在WinUser.h这个核心头文件中

import java.security.MessageDigest;

public class GenHash {

static String hex(byte\[\] b){StringBuilder s=new StringBuilder();for(byte x:b)s.append(String.format("%02x",x&0xff));return s.toString();}

String md5hex = hex(MessageDigest.getInstance("MD5").digest("123456".getBytes("UTF-8")));

System.arraycopy(secret,0,v,salt.length,secret.length);

System.arraycopy(raw,0,v,salt.length+secret.length,raw.length);

MessageDigest sha=MessageDigest.getInstance("SHA-256");

}

}
