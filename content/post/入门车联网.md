## 一、车联网攻击面分析

### 信息搜集

![1789094908644](../../chelianwang/media/1789094908644.png)

- **攻击入口概述**
  车联网存在多种攻击点，如GPS、T-Box（路由器、云端）、IVI（车载娱乐系统）、蓝牙、Wi-Fi、OBD、ADAS（辅助驾驶）等。

  ![1789095207043](../../chelianwang/media/1789095207043.png)

- 典型攻击场景
  - 利用格式化字符串漏洞进行远程代码执行。
  - 通过ADB调试模式获取车机root权限。
  - T-Box暴露公网导致远程攻击。
  - 充电桩PLC通信协议存在安全隐患。

![1789092839216](../../chelianwang/media/1789092839216.png)

这是大致的架构、可攻击点（功能越多、攻击点越多）

ICSE 2026发布的大规模实证研究分析了**649个真实漏洞**，揭示了车联网攻击面的真实分布：

```text
攻击面分布：- 远程信息处理/T-Box：31%- 车载信息娱乐系统：28%- 诊断接口/OBD-II：15% &nbsp;- V2X通信模块：12%- 传感器/ADAS：8%- 充电系统：6%
```

操作系统（嵌入式操作电脑）：安卓、DBA系的KingBase（和linux差不多）

最先尝试：蓝牙、WIFI（演示奥迪上的格式化字符串漏洞：CVE-2020-27524）

![1789093746016](../../chelianwang/media/1789093746016.png)

安卓车机进入开发者模式，通过adb shell拿到root权限

### 攻击面--TBOX

1. Desoldering the EMMC Chip

2. Dumping the firmware from Chip

3. Analyzing and extract the Private Key



   ### Pwn2Own 2026特斯拉IVI攻破

   1. **漏洞1：信息泄露**：通过特制USB设备，触发系统信息泄露漏洞，获取内存布局关键信息
   2. **漏洞2：越界写入**：利用第二个漏洞实现越界写入，覆盖关键内存区域
   3. **权限提升**：串联两个漏洞，成功获取系统root权限
   4. **代码执行**：在root权限下执行任意代码，完全控制信息娱乐系统

### 攻击面--充电桩

![1789093945153](../../chelianwang/media/1789093945153.png)

中国一般走CAN，供给面也很多（介绍一个：CVE-2021-34602，远程RCE）

- 充电桩类型与通信协议
  分为交流/直流充电桩，国标使用CAN协议，欧标使用PLC+TCP/IP。

- 施耐德充电桩漏洞分析

  - 硬编码后门账户（iter/open）。
  - 登录Token硬编码绕过身份验证。
  - 固件升级机制被利用实现远程RCE。

- **危害分析**
  可用于僵尸网络、横向渗透、电压控制破坏设备，甚至作为跳板攻击车辆本身，还有免费充电、窃取用户支付信息、向车辆传输恶意数据、控制充电过程（过充等安全风险）等等。

  **CAN注入攻击链**：

  1. 攻击者通过T-Box远程漏洞获得车内网络访问权限
  2. 逆向分析CAN报文，识别关键指令（如刹车、油门、转向）
  3. 构造伪造的制动指令报文，以高优先级发送到CAN总线
  4. ECU接收并执行伪造指令，车辆在高速行驶中意外刹车

### 攻击面--传感器

主要在自动驾驶里面

投影、人脸图片（人脸识别欺骗）、广告牌、指纹欺骗等等

### 攻击面-Keyfob

硬件上推荐支持RTL-SDR的电视棒，带有PortaPack模块的HackRF、RF干扰

无线钥匙与中继攻击

- **钥匙类型与通信机制**
  包括OOK/FSK调制方式、PTRVM/曼彻斯特编码等。

- 攻击方法演示

  - 干扰攻击：阻止车辆接收锁车信号。

  - 回放攻击：捕获并重放固定码信号。

  - 滚动码破解：利用频段漂移实现“肉酱攻击”。

    Hella系的汽车钥采用0OK调制模式，Manchester编码

    ![1789095170532](../../chelianwang/media/1789095170532.png)

- 中继攻击原理与实战演示

  - 中继攻击即中间人攻击，放大信号绕过距离限制。
  - 成功模拟对特斯拉NFC钥匙的中继攻击。

#### 数字钥匙与认证机制

- **数字钥匙发展历史**
  从机械钥匙 → 远控钥匙 → RFID防盗 → NFC/蓝牙数字钥匙演变。
- 后装数字钥匙漏洞分析
  - 安米智能钥匙存在逻辑缺陷：删除共享钥匙后仍可连接控制车辆。
  - 云端使用HTTP明文传输敏感信息，如IMEI码。

#### 特斯拉NFC钥匙分析

- **NFC协议结构与加密机制**
  支持ISO14443 Type A协议，采用Java卡架构和椭圆曲线加密。

- **APDU指令交互流程**
  包括选择AID、公钥交换、挑战响应验证等步骤。

- **中继攻击绕过时间限制**
  绕过选择AID阶段，节省响应时间以完成中继攻击。

**conversion_params**（转换参数）：

- 值为 `"-v -codec h264"`。
- 这是极其关键的内部信息。它揭示了后端服务器（可能是基于 FFmpeg 等工具）在对该视频进行转码时使用的**具体命令行参数**。`-v` 通常指代视频处理，`-codec h264` 表明服务器将其转码为了 H.264 编码格式。

这段响应体中还包含了 **id: 6**。这个 ID 通常对应数据库中的自增主键。如果 API 没有严格的权限验证（例如水平越权漏洞），攻击者可以通过修改 URL 或请求参数中的 ID（比如改成 1、2、3...），尝试获取其他用户的视频信息。
